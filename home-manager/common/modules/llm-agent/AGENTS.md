# AGENTS.md

## Git

- `git add` を実行する前
    - `git status` で変更を確かめる
    - `git diff` で変更を確かめる
- gitで管理しているファイルは `git rm` で消す
- コミットメッセージ
    - 英語で書く
    - 先頭にConventional Commitsのprefixを付ける
        - `feat:`
        - `fix:`
        - `docs:`
        - `style:`
        - `refactor:`
        - `test:`
        - `chore:`
- 1コミットは、件名1行で変更の全体を言える大きさに収める

## Pull Request

- PRのbody
    - 変更したことだけを書く
    - 3行以内に収める

## 何をどこに書くか

- アプリケーションコード
    - コードにはどう動くかを書く
- テストコード
    - コードには確かめる振る舞いを書く

## コメント

- 書いてよいもの
    - ユーザーの承認を得たもの
- 書く内容
    - コードから読み取れない意図
- コメントを書き換えるとき
    - 修正履歴に読めないよう、コメント全体を書き直す
