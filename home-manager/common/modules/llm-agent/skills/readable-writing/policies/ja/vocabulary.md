# 語彙

## 検出対象

### 英語固有名詞の律儀さ

製品名のたびに社名を添えてしまう。

#### AI版

```
OpenAIが発表したGPT-5は、Anthropicが発表したClaude 4や、Googleが発表したGemini 3よりも出力が速い。
```

#### 修正版

```
GPT-5の出力は、Claude 4とGemini 3より速い。
```

#### 修正の型

製品名だけで通じる場合は社名を書かない。

### 比喩動詞

何がどう変わったかを書かずに、動きのたとえで済ませている。

- `静かに壊れる`
    - `エラーを出さずに古い値を返す`
- `黙って無視される`
    - `警告を出さずに読み飛ばす`
- `安全側に倒す`
    - `失敗したら処理を止める`
- `1つずつ潰す`
    - `1つずつ直す`
- `地味に効く`
    - `ビルドが毎回20秒縮む`
- `時間を溶かす`
    - `半日かかった`

#### AI版

```
設定を保存した瞬間に、古いキャッシュが静かに壊れる。例外が出たときは安全側に倒す。
```

#### 修正版

```
設定を保存すると、古いキャッシュがエラーを出さずに前の値を返す。例外が出たらジョブを止める。
```

#### 修正の型

- 仕組みが分かる場合
    - 次を書く
        - 何が
        - どの条件で
        - どうなるか
- 仕組みが分からない場合
    - 書き手に確かめる
- 定着した言い方の場合
    - 残す
    - `テストが通る`
    - `キャッシュが効く`
- 慣用句の場合
    - 残す
    - `手を焼く`

### 直訳語

英語の術語や言い回しを一語ずつ日本語に写している。その分野の人が自分では使わない呼び名になる。

- `根因`
    - `根本原因`
- `この版では`
    - `このバージョンでは`
- `回帰が出た`
    - `リグレッションが出た`
- `依存の閉包`
    - `依存しているものすべて`
- `足すものがない`
    - `得られる利点がない`
- `背景実行`
    - `バックグラウンド実行`
- `耐力のある`
    - `欠かせない`
- `〜した瞬間に`
    - `〜するとすぐに`

#### AI版

```
根因は、新しい版でキャッシュの失効が効かなくなったことだった。
```

#### 修正版

```
根本原因は、v2.3でキャッシュの有効期限が切れても古い値を返すようになったことだった。
```

#### 修正の型

- 英語の術語を写した語の場合
    - その分野で定着した呼び名に戻す
        - `branch`
            - `ブランチ`
        - `version`
            - `バージョン`
- 英語の言い回しを写した句の場合
    - 前後の文から何が何をどうするかを確かめて書き直す
- 術語を日常語にくだした場合
    - その分野の術語に戻す
        - `受信側が生きているか`
            - `受信側の稼働状況`

### 役割を大げさに呼ぶ名詞

ただの決まりや一覧に重い名前を付けて、元の物に無い唯一性や拘束力を足している。

- `正本`
    - `原文`
    - `比較の基準`
- `台帳`
    - `一覧`
    - `記録`
- `ゲート`
    - `確認`
    - `チェック`
- `契約`
    - `ルール`
    - `取り決め`

#### AI版

```
`flake.lock` を正本とし、CIのゲートで差分を台帳と照合する。
```

#### 修正版

```
CIで `flake.lock` と各ホストの入力を比べ、差分があれば落とす。
```

#### 修正の型

- ただの基準や一覧を指す場合
    - 実際の役割を表す語にする
- 正式な名称の場合
    - 残す
    - `品質ゲート`
- 法律や会計の用語の場合
    - 残す
    - `固定資産台帳`

### 回りくどい言い回し

動詞1語で済む動作を名詞と補助の動詞で包んでいる。

- `〜することができる`
    - `〜できる`
- `〜を行う`
    - `〜する`
- `〜を実施する`
    - `〜する`
- `〜を活用する`
    - `〜を使う`
- `〜において`
    - `〜で`
- `〜に関して`
    - `〜について`
- `〜を可能にする`
    - `〜できるようにする`

#### AI版

```
本変更において、設定ファイルの読み込みを行うことで、ホストごとの切り替えを実施することが可能になった。
```

#### 修正版

```
設定ファイルを読み込んで、ホストごとに切り替えられるようにした。
```

#### 修正の型

- 名詞にした動作を動詞に戻す
- 何を扱うかの対象は落とさない

### 動詞から作った名詞

`確かめる` や `比べる` の連用形を名詞にして `の` で受けている。

- `結果の確かめ`
    - `結果を確かめる`
- `案の比べ`
    - `案を比べる`
- `値の補い`
    - `値を補う`

#### AI版

```
- 出力の確かめ
- 差分の比べ
```

#### 修正版

```
- 出力を確かめる
- 差分を比べる
```

#### 修正の型

- 動詞の形に戻す
- 定着した語は残す
    - `見直し`
    - `手直し`

### 表記ゆれ

- 1語で書いた形
    - `サーバー` と `サーバ`
    - `打ち合わせ` と `打合せ`
    - `1つ` と `一つ`
- 別の表記として数える形
    - 後ろにカタカナが続く複合語
        - `メモリリーク`
        - `サーバサイド`
    - 重ねた形
        - `一つ一つ`

#### AI版

```
サーバーを再起動したあと、サーバのログを確かめた。
```

#### 修正版

```
サーバーを再起動したあと、サーバーのログを確かめた。
```

#### 修正の型

- 元の表記のまま残す語
    - 引用
    - 固有名詞
    - コード
- リポジトリに表記の決まりがある場合
    - 決まりの表記にそろえる
- 決まりが無い場合
    - 文書で先に出てきた表記にそろえる

## 検出手順

1. 固有名詞を集める
    - 製品名に社名を添えていないか確かめる
2. 述語が動きのたとえになっている文を集める
    - 探す語
        - `壊れる`
        - `倒す`
        - `潰す`
        - `効く`
        - `溶かす`
3. 術語を集める
    - 英語に戻すと一語ずつ対応するか確かめる
    - その分野の人が自分で書くときに使う呼び名か確かめる
4. `の` のあとに動詞の連用形で終わる名詞が続く箇所を集める
5. 同じ語の書き方を集める
    - 2通り以上あるものを指摘する
