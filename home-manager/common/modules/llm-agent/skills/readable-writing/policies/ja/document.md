# 文書構成

## 検出対象

### 命題型の見出し

見出しの主張を本文冒頭で言い換える形も入る。

- ○○もまた同じ方向を指している
    - ○○の検証結果
- 実践で見えた3つの原則
    - 運用してみて分かったこと
- ○○は△△を失った瞬間に死ぬ
    - △△を外したときの影響
- なぜ我々は○○を選んだのか
    - ○○を選んだ理由
- ○○が私たちに教えてくれること
    - ○○の障害から分かったこと

#### AI版

```
## Pinecone Nexusもまた同じ方向を指している

実は、Pinecone Nexusというサービスもまた、これまで見てきた他のベクトル検索エンジンと同じ方向性を持っている。具体的には...
```

#### 修正版

```
## 検証結果

### Pinecone Nexus

検索のレイテンシが想定より高い。具体的には...
```

#### 修正の型

- 見出し
    - 何についての節かを名詞で示す
- 本文
    - 1文目にその節で扱う事実を書く

### メタ的な構造宣言

| 例 | 直し方 |
|---|---|
| `以下の3つの観点から説明します` | 消して1つ目を直接書く |
| `それぞれ順に見ていきましょう` | 消す |
| `ここからが本題です` | 消す |
| `補足ですが、` | 消して補足を直接書く |
| `○○について、改めて整理します` | 消す |
| `本セクションでは、` | 消す |

#### AI版

```
## RAGの基本

本セクションでは、RAGの基本概念について、以下の3つの観点から説明します。それぞれ順に見ていきましょう。

### 検索フェーズ
```

#### 修正版

```
## RAGの基本

### 検索フェーズ
```

### 太字のラベルで区切った節

`**目的**:` のようなラベルの太字は `scripts/mechanical.pl` が拾い、`fix` で `**` だけを外す。ラベルの行と節の中身は `fix` では直らない。

#### AI版

```
# 検索基盤の刷新

**目的**: 現行のElasticsearch 7系を8系に上げ、日本語の形態素解析器を
Kuromojiから Sudachi に置き換える。

**スコープ外**:
- 検索UIの変更
- ランキングロジックの変更
- インフラのIaC化
```

#### 修正版

```
# 検索基盤の刷新

## 目的

複合語の検索漏れをなくす。「機械学習」で検索すると「機械」と「学習」に分割され、無関係な文書が上位に来ている。

## 手段

- Elasticsearch
    - 7.17 -> 8.19
- 形態素解析器
    - Kuromoji -> Sudachi
```

#### 修正の型

- ラベルの行の場合
    - `##` の見出しにする
- 目的の節に手段を書いている場合
    - 目的の節には何に困っているかを書く
    - 手段は別の節に立てる
- スコープ外の節の場合
    - 消す
