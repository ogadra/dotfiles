# 記号

## パターン

### 評価を囲む鉤括弧

| AI版 | 修正版 |
|---|---|
| `「禁欲的」なAPI` | `機能を絞ったAPI` |
| `ある「真実」` | `分かったこと` |

### 間を作る読点

- 文頭の短い主題のあとで、別の主語を挟まずに述部が続く所
    - `原因は、`
    - `CIでは、`
- `を` のあと
    - `ハッシュを、`

#### AI版

```
原因は、キャッシュのキーの誤りだった。`package-lock.json` のハッシュを、キーに含めた。
```

#### 修正版

```
原因はキャッシュのキーの誤りだった。`package-lock.json` のハッシュをキーに含めた。
```

#### 修正の型

- 外しても掛かり先が変わらない読点の場合
    - 読点だけを外す
- 外すと掛かり先が変わる読点の場合
    - 残す
        - `店長は、慌てて逃げた客を追いかけた`

### 全角の英数字

| AI版 | 修正版 |
|---|---|
| `２０２６年` | `2026年` |
| `ＡＰＩ` | `API` |

#### AI版

```
キャッシュを足して、ＣＩの所要時間を９分から３分に縮めた。
```

#### 修正版

```
キャッシュを足して、CIの所要時間を9分から3分に縮めた。
```

#### 修正の型

`scripts/mechanical.pl` の `fix` はインラインコードとURLの外にある全角の英数字を半角にする。

- 正式な表記が全角の固有名詞を含む場合
    - 固有名詞の外だけを手で半角にする
- 含まない場合
    - `fix` をそのまま使う

## 検出手順

1. 鉤括弧で囲んだ語を集める
    - 固有名詞を外す
    - 直接引用を外す
    - 残ったものを指摘する
2. 読点を集める
    - 直前が文頭の短い主題のものを指摘する
    - 直前が `を` のものを指摘する
3. 全角の英数字を集める
