# 記号

## 検出対象

### 評価を囲む鉤括弧

- `「禁欲的」なAPI`
    - `機能を絞ったAPI`
- `ある「真実」`
    - `分かったこと`

### 間を作る読点

読み手が止まる必要のない所に読点を打っている。

- 文頭の短い主題のあと
    - `原因は、`
    - `CIでは、`
- `を` のあと
    - `ハッシュを、`

#### AI版

```
原因は、キャッシュのキーの誤りだった。`package-lock.json` のハッシュを、キーに含めた。
```

#### 修正版

```
原因はキャッシュのキーの誤りだった。`package-lock.json` のハッシュをキーに含めた。
```

#### 修正の型

- 読点だけを外す
    - 語順と述語は変えない
- 残す読点
    - 外すと掛かり先が変わる所
        - `店長は、慌てて逃げた客を追いかけた`
    - 主題のあとに別の主語が続く所
        - `会議では、担当者が説明した`
    - 長い条件や理由のあと
        - `キーを変えたので、`
    - `が` や `けど` で2つの文をつないだ所
    - 文頭の接続語のあと
        - `ただ、`
        - `まず、`
    - 並べた語の間
    - 定義の `〜とは、` のあと

## 検出手順

1. 「」で囲んだ語を集める
    - 固有名詞でも直接引用でもないものを指摘する
2. 読点を集める
    - 直前が文頭の短い主題のものを指摘する
    - 直前が `を` のものを指摘する
    - 間を作る読点の残す読点に当たるものは除く
