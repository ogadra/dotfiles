# 各フィールドの入れ方

- `line`
    - 1箇所か2箇所の場合
        - 行番号か行の範囲を入れる
            - `12-18`
    - 同じ形が3箇所以上に出る場合
        - 指摘を代表1件にまとめる
        - 該当する行をすべて並べて入れる
            - `12, 40, 88`
- `quote`
    - 本文に実在する文字列をそのまま入れる
- `category`
    - 規則が1つのディレクトリにだけある場合
        - その `###` 見出しの名前を1つだけ入れる
    - 同じ規則が `common/` と言語別ディレクトリの両方にある場合
        - `common/` の見出しの名前を入れる
- `problem`
    - 何が読みにくいかを1文で書く
