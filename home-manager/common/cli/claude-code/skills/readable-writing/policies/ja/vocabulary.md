# 語彙

語彙を見る。

## 検出対象

### 英語固有名詞の律儀さ

正式名称を毎回フルで書く形。

#### AI版

```
OpenAIが発表したGPT-5は、Anthropicが発表したClaude 4や、Googleが発表したGemini 3よりも出力が速い。
```

#### 修正版

```
GPT-5の出力は、Claude 4とGemini 3より速い。
```

#### 修正の型

2度目以降は社名やバージョンを省略する。

## 検出手順

1. 固有名詞を集める
    - 2度目以降が省略されているか確かめる
    - フル正式名称が3つ以上並んだら指摘する
