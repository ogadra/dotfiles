## 検出手順

1. 語り手を指す語を探す
    - 探す語
        - `人々`
        - `多くの`
        - `我々`
        - `エンジニアは`
    - 主語を書き手自身に置き換えられる場合
        - 指摘する
2. 翻訳調動詞のリストで探す
    - 主語が無生物の場合
        - 指摘する
3. 受動態を探す
    - 探す語
        - `〜された`
        - `〜が行われた`
        - `〜が求められている`
    - 行為者が本文に出てこない場合
        - 指摘する
4. 主語が無生物の文を集める
    - 述語が人の行為の場合
        - 指摘する
    - 述語が他動詞と対をなす自動詞の場合
        - 探す語
            - `が消える`
            - `が直る`
            - `が通る`
            - `が変わる`
            - `が減る`
            - `が増える`
            - `が速くなる`
        - 書き手がその変化を起こした場合
            - 指摘する
5. 壮大化の語を探す
    - 探す語
        - `思想`
        - `文化`
        - `美学`
        - `体現`
    - 直前が実装や設定の記述の場合
        - 指摘する
