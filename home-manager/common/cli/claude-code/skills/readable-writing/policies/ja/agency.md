# 主体

主体が消える言い回しを扱う。

## 検出対象

### false agency

| AI版 | 修正版 |
|---|---|
| データが示している | データを見るとこうなっている |
| 文化が醸成される | 経営陣が文化を作った |
| 課題が浮き彫りになる | やってみて課題に気付いた |
| 思想が結実する | 設計者がそう作った |
| 複雑性が増していく | 機能を足しすぎた |
| 自然と最適化されていく | チームで少しずつ直した |
| 市場が報いる | 顧客が買ってくれる |
| 議論が深まる | 話してたら細かい話まで出てきた |
| 解像度が上がる | 分かるようになってきた |
| アーキテクチャが導く | 設計者がそう決めた |
| プロセスが定着する | みんながやるようになった |
| 議論が続いている | コア開発者が議論している |
| 価値が再認識されるようになった | 肯定的な開発者が増えてきているようだ |

#### AI版

```
Pythonコミュニティでは、長年Type Hintsの議論が続いている。一方でTypeScriptの成功事例から、静的型付けの価値が再認識されるようになった。
```

#### 修正版

```
Pythonのコア開発者は、何年もType Hintsの扱いを議論している。TypeScriptがうまくいったのを見て、静的型付けに肯定的な開発者が増えてきているようだ。
```

「コア開発者」を主語に立てて現在形にすると、誰が議論しているのかが読み手に伝わる。伝え聞いた部分は「ようだ」に落とす。

### 実装判断の壮大化

| AI版 | 修正版 |
|---|---|
| このリトライ設計が、システムの回復力に対する思想を体現している | タイムアウトしたら3回まで再送するだけ |
| モノレポへの移行が、組織のコミュニケーション構造を映し出す | リポジトリを1つにしたら、レビュー依頼の宛先が分かりやすくなった |
| CIの高速化が、開発文化そのものを変えた | CIが12分から3分になって、PRを小さく出すようになった |
| この命名規則には、チームの美学が凝縮されている | チームで話し合って命名規則を決めた |

### 受動態

| AI版 | 修正版 |
|---|---|
| 〜が決定された | 誰が決めたかを書く |
| 〜が行われた | 誰がやったかを書く |
| 〜が求められている | 誰が求めているかを書く |

### 遠くから語る話者

| AI版 | 修正版 |
|---|---|
| 人々は〜する傾向にある | 自分も含めて、〜してしまう |
| 現代社会において、〜は重要だ | 最近、〜が気になる |
| 誰もが〜を経験したことがあるはずだ | 自分は〜を経験した |
| 組織はしばしば〜する | 自分の会社では〜だった |
| エンジニアは〜と考えがちだ | 自分は〜と思っていた |
| 多くのエンジニアが | 自分も |

### 一人称の消失

| AI版 | 修正版 |
|---|---|
| 多くのエンジニアが、TypeScriptの型定義に頭を悩ませている | 自分もTypeScriptの型定義でずっと困っている |
| プロダクト開発では、フィードバックの優先順位付けが重要である | 去年、同じボタンについて3人から文句を言われて直したら、別の人に前のほうがよかったと言われた |
| ユーザーの声を取り入れることは、継続的な改善につながる | それ以来、フィードバックが来ても3日寝かせるようにしている |

### 翻訳調動詞

主体を抽象化した分析動詞。英語の `point to` `suggest` `emerge` をそのまま訳すとこうなる。false agencyを動詞ひとつの単位でやった形だ。

- 指している
- 示している
- 示唆している
- 物語っている
- 浮かび上がる
- 見えてくる
- 対比をなしている
- 収斂する
- 整理する
- 考察する
- 捉える
- 論じる
- 位置づける

#### AI版

```
このベンチマークの結果は、キャッシュの効果が環境に依存することを示唆している。ログを整理すると、待ち時間の偏りが浮かび上がる。
```

#### 修正版

```
このベンチマークでは、CIランナーが4コアのときだけキャッシュの効果が出た。ログを見ると、待ち時間は月曜の朝に偏っている。
```

#### 修正の型

主語を人か組織に変えて、動詞を普通の動詞に戻す。

### アカデミック自称

次の語を地の文で使うと、翻訳論文の口調になる。

- `本稿`
- `本記事`
- `本論考`
- `筆者`

#### AI版

```
本稿では、CIの高速化について論じる。筆者はキャッシュの導入を推奨する。
```

#### 修正版

```
この文書はCIの高速化を扱う。自分はキャッシュを入れた。
```

#### 修正の型

「この文書」に変えるか、主語ごと消す。一人称が要る場面では「自分」を使う。

## 検出手順

1. 次の語で検索する
    - 「人々」
    - 「多くの」
    - 「我々」
    - 「エンジニアは」
2. 翻訳調動詞のリストで検索する
    - 主語が無生物の場合
        - 指摘する
3. アカデミック自称のリストで検索する
4. 次の語で検索する
    - 「〜された」
    - 「〜が行われた」
    - 「〜が求められている」
    - 行為者が本文に出てこない場合
        - 指摘する
5. 主語が無生物の文を集める
    - 述語が人の行為の場合
        - 指摘する
6. 次の語で検索する
    - 「思想」
    - 「文化」
    - 「美学」
    - 「体現」
    - 直前が実装や設定の記述の場合
        - 指摘する
