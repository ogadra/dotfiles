# 記号

AIが書く文章に固有の記号を見る。

## 検出対象

### 全角ダッシュ

英語のem dashの直輸入。

#### AI版

```
リトライは3回まで──それを超えたらDLQに送る。
キャッシュのキー──`package-lock.json` のハッシュ──を見直した。
```

#### 修正版

```
リトライは3回まで。それを超えたらDLQに送る。
キャッシュのキーである`package-lock.json`のハッシュを見直した。
```

#### 修正の型

- 前後が名詞と説明の場合
    - 「は」「とは」で繋ぐ
- 前後が別の文の場合
    - 改行して2文にする
- 前後が同じ文の要素の場合
    - 読点にする

### 中黒並列

`A・B・C` の形で並列を作る形。

#### AI版

```
対応環境はNode.js・pnpm・Dockerの3つ。ログはINFO・WARN・ERRORの3段階で出す。
```

#### 修正版

```
ログはINFO、WARNとERRORの3段階で出す。対応環境は次の3つ。

- Node.js
- pnpm
- Docker
```

#### 修正の型

- 地の文の場合
    - 読点で並べ、最後の項目だけ `と` `や` で繋ぐ
- 3項目以上の場合
    - 箇条書きにする

### 地の文のコロン

英語の `:` を地の文に持ち込む形。前を予告して後ろで受ける働きをする記号は日本語にない。

#### AI版

```
重要な要素： テクノロジーと人間性の融合。
対応環境: Node.js 20.1以上
```

#### 修正版

```
重要な要素はテクノロジーと人間性の融合だ。

## 対応環境

- Node.js
    - 20.1以上
```

#### 修正の型

- 「は」「とは」で繋ぐ
- 改行する
- 見出しにする

コロンを使うのはコードと、コードの中の記法だけ。

### 不要な半角スペース

書き手が半角スペースを入れてしまう形。

#### AI版

```
SEO対策には 次の施策を使う。
Node.js 20 以上が必要。Docker が起動していること。
```

#### 修正版

```
SEO対策には次の施策を使う。
Node.js 20以上が必要。Dockerが起動していること。
```

#### 修正の型

- 全角文字どうしの間の半角スペースを削除する
- 半角英数字と全角文字の境界の半角スペースを削除する

### 評価を囲む鉤括弧

形容詞や評価を「」で囲む形。

| AI版 | 修正版 |
|---|---|
| 「禁欲的」なAPI | 機能を絞ったAPI |
| ある「真実」 | 分かったこと |

#### 修正の型

鉤括弧を使うのは固有名詞と直接引用だけ。

## 検出手順

1. `──` を検索する
2. `・` を検索する
    - 地の文の並列に使っている箇所を集める
3. `:` と `：` を検索する
    - コードブロックの外にある箇所を集める
4. 全角文字に挟まれた半角スペースを検索する
5. 半角英数字と全角文字の境界の半角スペースを検索する
6. 「」で囲んだ語を集める
    - 固有名詞でも直接引用でもないものを指摘する
