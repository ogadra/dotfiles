## 全角ダッシュ

英語のem dashの直輸入。本文に混入していないか検索する。

置換先は前後の関係で決まる。

- 前後が名詞と説明の場合
    - 「は」「とは」で繋ぐ
- 前後が別の文の場合
    - 改行して2文にする
- 前後が同じ文の要素の場合
    - 読点にする

## 中黒並列

`A・B・C` の形で並列を作る形。

- 地の文の場合
    - `と` `や` で繋ぎ直す
- 3項目以上の場合
    - 箇条書きにする

## 地の文のコロン

英語の `:` を地の文に持ち込む形。この働きをする記号が日本語にはない。

### AI版

```
重要な要素： テクノロジーと人間性の融合。
対応環境: Node 20以上
```

### 修正版

```
重要な要素はテクノロジーと人間性の融合だ。

## 対応環境

- Node 20以上
```

### 修正の型

「は」「とは」で繋ぐか、改行するか、見出しにする。コロンを使うのはコードと、コードの中の記法だけ。

コロンで終わる裸の行が見出しの位置にある場合は `common/document.md` の見出しの代用を参照。

## 不要な半角スペース

書き手が半角スペースを入れてしまう形。全角文字どうしの間に入るものと、半角英数字との境界に入るものがある。

### AI版

```
SEO対策をする ためには以下の ような施策が効果的だ。
Node 20 以上が必要。Docker が起動していること。
```

### 修正版

```
SEO対策をするためには以下のような施策が効果的だ。
Node 20以上が必要。Dockerが起動していること。
```

### 修正の型

- 全角文字どうしの間の半角スペースを削除する
- 半角英数字と全角文字の境界の半角スペースを削除する
- バッククォートに接する半角スペースは残す
    - `` `pnpm install` を実行する ``
    - バッククォートが区切りを兼ねるので、読み手は空白があっても読み違えない

## 評価を囲む鉤括弧

形容詞や評価を「」で囲む形。

| AI版 | 修正版 |
|---|---|
| 「禁欲的」なAPI | 機能を絞ったAPI |
| ある「真実」 | 分かったこと |

鉤括弧を使うのは固有名詞と直接引用だけ。

## 検出手順

1. `──` を検索する。
2. `・` を検索し、地の文の並列に使われている箇所を集める。
3. `:` `：` を検索し、コードブロックの外にある箇所を集める。
4. 全角文字に挟まれた半角スペースを検索する。
5. 半角英数字と全角文字の境界の半角スペースを検索し、バッククォートの外にあるものを集める。
6. 「」で囲まれた語を集め、固有名詞と直接引用でないものを指摘する。
