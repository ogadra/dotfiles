# 文書構成

パターンと直し方は `common/document.md` にある。ここには日本語の言い回しと例を置く。

## 命題型の見出し

| AI版 | 修正版 |
|---|---|
| ○○もまた同じ方向を指している | ○○の検証結果 |
| 実践で見えた3つの原則 | 運用してみて分かったこと |
| ○○は△△を失った瞬間に死ぬ | △△を外したときの影響 |
| なぜ我々は○○を選んだのか | ○○を選んだ理由 |
| ○○が私たちに教えてくれること | ○○の障害から分かったこと |

見出しの言い換えで本文を始める形。

### AI版

```
## Pinecone Nexusもまた同じ方向を指している

実は、Pinecone Nexusというサービスもまた、これまで見てきた他のベクトル検索エンジンと同じ方向性を持っている。具体的には...
```

### 修正版

```
## Pinecone Nexusの検証結果

Pinecone Nexusを3週間検証した。まず問題になったのは、検索のレイテンシが想定より低かったこと。具体的には...
```

修正版は「3週間検証した」から入っているので、「同じ方向を指している」のような抽象的な主張を置く場所がなくなる。

## 見出しの代用と対象外の列挙が同時に出る例

設計文書の冒頭。

### AI版

```
# 検索基盤の刷新

**目的**: 現行のElasticsearch 7系を8系に上げ、日本語の形態素解析器を
Kuromojiから Sudachi に置き換える。

**スコープ外**:
- 検索UIの変更
- ランキングロジックの変更
- インフラのIaC化
```

### 修正版

```
# 検索基盤の刷新

## 目的

複合語の検索漏れをなくす。「機械学習」で検索すると「機械」と「学習」に分割され、無関係な文書が上位に来ている。

## 手段

- Elasticsearchを7系から8系に上げる
- 形態素解析器をKuromojiからSudachiに置き換える
```

太字を見出しに変えた。スコープ外の節は削り、「目的」には何が困っているかを書いた。手段は別の節に移した。

文中の改行は `common/symbols.md` にも載っている。
