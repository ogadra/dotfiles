# 判定ルール

- `common/` にあるもの
    - パターン
    - 直し方
- `ja/` と `en/` にあるもの
    - その言語の言い回し
    - その言語の例
- 両方を突き合わせて判定する
- 1つの文書に日本語と英語が混ざる場合
    - 箇所ごとに言語を判定する
- コードブロックの中身
    - 対象にしない
- 意図的な例として扱う見出しの下
    - `AI版`
    - `Before`
- ここまでに読んだポリシーで説明できるものだけを指摘する
- 同じ形が3箇所以上に出る場合
    - 代表1件にまとめる
    - 他の該当行を `line` に列挙する
