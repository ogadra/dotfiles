# 判定ルール

`common/` がパターンと直し方、`ja/` と `en/` がその言語の言い回しと例を持つ。両方を突き合わせて判定する。

- 1つの文書に日本語と英語が混ざる場合
    - 箇所ごとに言語を判定する
- コードブロックの中身
    - 対象にしない
- 意図的な例として扱う見出しの下
    - `AI版`
    - `Before`
- `fix` に書く文
    - 検出対象のどれにも当たらない形にする
        - 列挙を畳むと `1項目への詰め込み`、開くと `3項目並列` や `文頭のクセ` になる場合、共通の語を親項目に寄せるなどして組み替える
- ここまでに読んだポリシーで説明できるものだけを指摘する
- 同じ形が3箇所以上に出る場合
    - 代表1件にまとめる
    - 他の該当行を `line` に列挙する
