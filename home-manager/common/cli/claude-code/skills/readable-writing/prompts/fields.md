# 各フィールドの入れ方

- `line`
    - 行番号
    - 範囲
        - `12-18`
- `quote`
    - 本文に実在する文字列をそのまま入れる
- `category`
    - 該当する `### ` 見出しを1つだけ、文字列のまま写す
    - 同じ規則が `common/` と `ja/` `en/` の両方にある場合
        - `common/` の見出しを写す
- `problem`
    - 何が読みにくいかを1文で
- `fix`
    - 書き換え案の文そのもの
    - 消して終わる場合
        - 消す範囲を書く
            - `目的 の節(1-3行)を消す。`
